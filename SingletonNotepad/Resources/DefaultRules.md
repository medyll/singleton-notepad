# Singleton Notepad — Normalization Rules

Define how your notes should be structured. These rules are sent to the LLM
before each normalization. Edit freely — changes take effect immediately.

## Default Rules

- Maintain clear heading hierarchy (H1 → H2 → H3)
- Group related content under appropriate headings
- Remove redundant whitespace and empty lines (max 1 blank line between sections)
- Preserve all meaningful content — never delete user data
- Use consistent list formatting (dashes for unordered, numbers for ordered)
- Keep code blocks intact with proper language tags
- Standardize date format to YYYY-MM-DD
- Use French for UI labels, English for technical content
