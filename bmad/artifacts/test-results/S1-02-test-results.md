## Changes Implemented

### IFileService.cs
- Added `IDisposable` inheritance
- Added `event Action? FileSaved`
- Added `event Action<Exception>? SaveFailed`
- Added `void ScheduleSave(string content)` — 2s debounced save
- Renamed `WatchAsync` → `Watch` (synchronous return of IDisposable)

### FileService.cs
- Debounce: `System.Threading.Timer` reset via `Timer.Change(2000, Timeout.Infinite)` on each `ScheduleSave` call
- `OnDebounceElapsed`: fires `FileSaved` on success, `SaveFailed` on exception
- `LoadAsync`: auto-creates parent directory if absent
- `SaveAsync`: unchanged (retry 3× with 200/400/800ms backoff)
- `IDisposable.Dispose`: cleans up `_debounceTimer`

### MainViewModel.cs
- Constructor: subscribes `FileSaved → OnFileSaved`, `SaveFailed → OnSaveFailed`
- `partial void OnEditorContentChanged`: sets `SyncState.Unsaved`, calls `ScheduleSave` (guarded by `_loading`)
- `OnFileSaved`: sets `SyncState.Saved`, `StatusMessage = "Sync ✓"`
- `LoadFileAsync`: uses `_loading` flag to suppress debounce on programmatic content assignment
- Fixed incorrect `SyncState.Saving` during load (was a bug)

### MainView.xaml
- Replaced non-WinUI3 `<StatusBar>` / `<StatusBarItem>` with `<Border>` + `<Grid>` status bar
- Fixed WPF-style `KeyboardAccelerator="Ctrl+F"` → proper WinUI 3 element syntax

### FileServiceTests.cs
- `ScheduleSave_SavesContent_AfterDebounce` — waits for FileSaved event (≤3s), verifies file content
- `ScheduleSave_ResetsTimer_OnRapidCalls` — rapid calls, only last content saved
- `Watch_ReturnsDisposable_WithoutThrowing`
