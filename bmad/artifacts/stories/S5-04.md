# S5-04 — UI Fix: Scrollbar Hidden When Input Empty

**Sprint:** S5 · **Priority:** Low · **Status:** todo

## User Story

As a user, I don't want to see a scrollbar on the text input area when it's empty, so the UI looks clean at startup.

## Description

The editor/input zone shows a scroll indicator even when content is empty. Expected behavior: scrollbar visible only when content overflows.

> Assumed: Issue is in the WebView2/TipTap editor CSS — `overflow: auto` or `overflow-y: scroll` set unconditionally. Fix: set `overflow-y: auto` and ensure min-content height doesn't trigger scroll.

## Acceptance Criteria

- [ ] On fresh launch with empty file: no scrollbar visible in editor area
- [ ] Scrollbar appears only when content exceeds visible editor height
- [ ] Fix does not break existing scroll behavior with long content
- [ ] No regression in editor resize behavior

## Notes

Quick CSS fix in the TipTap/WebView2 editor styles.
