## Implementation Notes

- Runtime: **.NET 10** (`net10.0-windows10.0.26100.0`)
- `Package.appxmanifest` must declare `broadFileSystemAccess` capability
- DI registration: singleton for ISettingsService, IFileService; transient for ViewModels
- Use CommunityToolkit.Mvvm source generators (`[ObservableProperty]`, `[RelayCommand]`)
- Single-instance: named Mutex + P/Invoke `FindWindow` / `SetForegroundWindow` (NOT `AppInstance.FindOrRegisterForKey`)
- Expose `static App Current` cast and `IServiceProvider Services` for code-behind DI resolution
- Build command: `dotnet build -p:Platform=x64` — never bare `dotnet build`
