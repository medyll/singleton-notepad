# S5-01 — Chat Bubble (Floating LLM Chat Panel)

**Sprint:** S5 · **Priority:** High · **Status:** todo

## User Story

As a user, I want a floating chat bubble that lets me ask questions or request modifications on my note content, so I can interact with LLM without leaving the editor.

## Description

A chat panel anchored at bottom-right of the main window. Can be:
- **Expanded** — full chat panel (input + history)
- **Minimized** — small floating icon button
- **Hidden** — no visible element (toggle via menu or shortcut)

Chat scope:
- **Selected text** — when editor has a selection, chat context = selected text
- **Full content** — no selection, context = entire note

LLM model used = the model configured in Settings (provider + model from S5-02).

> Assumed: Responses shown inline in chat panel, not auto-applied to note. User must explicitly click "Apply" to replace content.

## Acceptance Criteria

- [ ] Chat bubble visible in main window (bottom-right)
- [ ] Click bubble → expands to chat panel
- [ ] Chat panel has: message history, text input, Send button
- [ ] Minimize button collapses panel back to icon
- [ ] Hide/show toggle in View menu (or `Ctrl+Shift+C`)
- [ ] When editor selection exists → system prompt includes selected text as context
- [ ] When no selection → system prompt includes full note content
- [ ] LLM response streamed into chat history
- [ ] "Apply" button replaces selection (or full content) with LLM response
- [ ] Chat panel state (open/closed) persists across sessions via LocalSettings
- [ ] Works with all configured providers (Ollama, OpenAI, Anthropic)

## Out of Scope

- Conversation history persistence across sessions
- Multiple chat threads
- Drag-to-reposition bubble
