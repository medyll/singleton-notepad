# Story S1-04: MainWindow positioning (primary monitor, restore/center fallback)

**Status:** complete  
**Role:** Developer  
**Phase:** development  
**Depends on:** S1-03 (SettingsService with window geometry)

---

## Acceptance Criteria

- [ ] `MonitorHelper.IsOnPrimaryMonitor()` correctly detects if coordinates are within primary monitor bounds
- [ ] `MonitorHelper.CenterOnPrimaryMonitor()` centers window on primary monitor with given dimensions
- [ ] `MainWindow.RestoreWindowPosition()` validates saved position is on primary monitor
- [ ] If saved position is off-screen or invalid, fallback to centered position on primary monitor
- [ ] Window geometry persists correctly across app restarts (S1-03 integration)
- [ ] Unit tests for `MonitorHelper`:
  - IsOnPrimaryMonitor with valid/invalid coordinates
  - CenterOnPrimaryMonitor calculates correct position
- [ ] Integration test: Window position save/restore round-trip
- [ ] Handle edge cases:
  - Monitor disconnected since last save
  - Resolution changed since last save
  - Window would be partially off-screen

---

## Implementation Notes

- Use `System.Windows.Forms.Screen` for monitor detection (already in MonitorHelper)
- Primary monitor is `Screen.PrimaryScreen`
- Validate window is fully visible (not just top-left corner)
- Minimum visible area: 50% of window should be on-screen
- Centering formula: `(screen.WorkingArea.Width - windowWidth) / 2`
- Consider taskbar when centering (use `WorkingArea` not `Bounds`)
