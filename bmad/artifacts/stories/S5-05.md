# S5-05 — ChatBubble Redesign

**Sprint:** S5 · **Priority:** High · **Status:** todo

## User Story

As a user, I want the chat bubble to be clean, minimal, correctly positioned, and comfortable to type in.

## Changes

### Naming
- Rename `ChatPanelState` → `ChatBubbleState` everywhere (AppSettings, ChatViewModel, ChatService, SettingsViewModel)
- Rename internal `ChatPanel` XAML name → `ChatExpanded`

### Layout & Position
- Width: fill horizontally with margin (e.g. `HorizontalAlignment="Stretch"` with `Margin="16,0,16,0"`)
- Height: 200px fixed
- Position: centered at bottom, above status bar — use `VerticalAlignment="Bottom"` with bottom margin = statusbar height (~36px) + 8px gap
- Must NOT overlap the status bar row

### Simplification
- Remove Close button entirely (hidden state not needed if minimized is the lowest state)
- Toggle: `open` ↔ `minimized` only (no `hidden` state — remove from `TogglePanel` logic)
- Default state: `minimized`

### Header
- Remove title "Assistant IA" text from header
- Keep only the Minimize/Expand toggle button in header (one button, changes glyph based on state)

### Input area
- Replace single-line `TextBox` with multi-line `TextBox` (`AcceptsReturn="False"`, `TextWrapping="Wrap"`)
- Default height: ~3 lines (~72px)
- Max height: 50% of window height → use `MaxHeight` binding or fixed `200px` cap (window is typically 800px → 400px max)
- Input grows as user types (use `ScrollViewer` wrapping or auto-grow via `MinHeight`/`MaxHeight`)

## Acceptance Criteria

- [ ] `ChatBubbleState` used everywhere (no remaining `ChatPanelState` references)
- [ ] Chat bubble spans full width minus 16px margins on each side
- [ ] Chat bubble height = 200px, positioned above status bar
- [ ] No close button — only expand/minimize toggle
- [ ] No title in header — just the toggle button
- [ ] Input is multi-line, min 3 lines, grows up to 200px max
- [ ] Toggle: minimized → open → minimized (no hidden state from toggle)
- [ ] Minimized state shows floating pill/button at bottom center
