# S5-06 — Spell Check Language Live Refresh

**Sprint:** S5 · **Priority:** High · **Status:** todo

## User Story

As a user, when I change the spell check language in Settings and return to the editor, I want the editor to immediately reflect the new language without restarting the app.

## Root Cause

`ApplySpellCheckSettingsAsync` is called once in `OnEditorWebViewLoaded`. Settings changes saved correctly (race condition fixed in previous session) but editor lang attribute never refreshed until restart.

## Fix

- In `MainPage.OnNavigatedTo`, call `_ = ApplySpellCheckSettingsAsync()` when returning from settings (i.e., when editor is already initialized)
- Guard: only fire if `_editorInitialized` is true (editor already loaded)

## Acceptance Criteria

- [ ] Change language in Settings → navigate back → editor spell check language updates immediately
- [ ] Status bar shows updated language after return from Settings
- [ ] No flicker or content loss in editor on language refresh
- [ ] Works for all three options: auto, fr-FR, en-US
